# Simulation Modes

Simulation mode is chosen during commissioning and affects narrative severity.

## Command mode

- full causal handling
- strongest consequence model
- player and senior staff choices can create significant operational cost
- no guaranteed survival for officers when rules say risk is real

## Exploration mode

- command pressure is lighter for non-critical failures
- senior staff are still authoritative where the mission rules require it
- can feel more forgiving for discovery and first-pass play

Both modes remain in authored mission logic.
The difference is in consequence intensity and fallback behavior, not interface layout.
