# Privacy, Security, and Data

Directive is built as player-safe projections over a host-owned backend.

## Where your data lives

Your campaign state and history are stored by your active host.
Directive stores only the projection and campaign-domain records needed for play.

## What Directive intentionally omits

- private character psychology
- hidden motive chains
- unrevealed mission details
- future plot seeds
- raw provider credentials

## What is exposed to you

You can see player-safe mission facts, crew public records, ship systems, and outcome records.
If something was not observed and proven by accepted state, it should not appear.

## Storage safety

Directive does not accept manual save hand-editing.
Unknown state files are ignored or rejected based on version check.

## Recovery posture

Use host and Directive recovery tools for mismatch warnings.
Manual file surgery is not a supported repair path.
