# Interface Guide

Directive is shown as a full-window panel with five routes:

- Campaign
- Mission
- People
- Ship
- Settings

You can close the panel with Escape or the close action.
Focus returns to the Directive launcher button.

## Campaign route

Campaign is where setup and active-campaign status live.

Current modes are:

- Command: active campaign overview
- Library: available packages
- Records: campaign records and active lineage info

## Mission route

Mission shows:

- active mission title and status
- primary and optional objectives
- known facts and outcome record
- latest outcome transition summary
- current Command Bearing summary

## People route

People shows public contact records discovered through play.
Observed contacts appear as cards.
Missing or unrevealed data stays unavailable.

## Ship route

Ship shows:

- ship cohesion score and band
- active systems and visible limits
- current and resolved assignment work
- operational constraints and capabilities
- recent assignment history

## Settings route

Settings focuses on authority and host ownership boundaries.
It confirms:

- active campaign authority mode
- committed campaign status
- where model configuration is set
