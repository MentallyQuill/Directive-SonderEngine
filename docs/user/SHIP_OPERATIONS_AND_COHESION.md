# Ship Operations and Cohesion

The Ship view shows what matters to command execution.

## What cohesion means

Cohesion is Directive’s operational readiness score for mission tempo and reliability.
It changes with completed work, stress, and major outcomes.

## Assignment work

Ship work appears as assignments with:

- title and phase
- next required effect
- operational reward (often cohesion)
- resolved history

Assignments must be completed by play context.
There is no instant project-completion action.

## Systems and capabilities

Ship systems section includes:

- current system state
- visible mechanical effect
- pending and resolved work orders
- constraints that affect mission options

## Why this matters at command level

System limits and crew assignments can constrain options before you make a call.
Read Ship before giving a command that depends on logistics, power, engineering, or medical readiness.
