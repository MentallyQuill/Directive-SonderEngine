# Player Guide

Directive is prose-first.
You write normal player text; the systems evaluate whether the story rules can accept it.

## How to play effectively

Use one sentence per move if you want, or one longer message.
Focus on what your command choice changes in the scene.

- state your intent clearly
- avoid overloading one message with unrelated threads
- accept consequences if there is a meaningful trade-off
- read Mission/People/Ship before the next decision

## Keep these screens open

- Mission for current objectives, outcome dimensions, and known facts.
- People for contact history, service records, and Command Bearing status.
- Ship for assignment readiness, active limitations, and operational effects.
- Settings for authority boundaries and model/source ownership state.

## What changes do not happen

Directive does not invent private character motives.
It only shows public facts that are approved through accepted mission events.

## Tone and style expectations

Directive favors grounded command language.
There are no hidden UI dice.
If a line is too broad or contradictory to established setup, system checks reject or reshape through normal host behavior.
